# Sliding window

## Когда применять

Паттерн для задач про **непрерывный подмассив или подстроку**, где условие можно
поддерживать при сдвиге границ: сумма, число различных элементов, частоты символов.
Вопросы вида «самая длинная / самая короткая / максимальная сумма … подряд».

Решение «в лоб» перебирает все отрезки — O(n²) пар начало/конец и ещё O(n) на проверку
каждого. Окно даёт O(n): каждая граница проходит массив **один раз**.

## Окно фиксированной длины

Максимальная сумма k подряд идущих элементов:

```js
function maxSumOfK(nums, k) {
  if (k > nums.length) return null;
  let windowSum = 0;
  for (let i = 0; i < k; i++) windowSum += nums[i];
  let best = windowSum;
  for (let i = k; i < nums.length; i++) {
    windowSum += nums[i] - nums[i - k]; // вошёл новый, вышел старый
    best = Math.max(best, windowSum);
  }
  return best;
}
```

Пересчитывать сумму окна заново — O(n·k). Обновлять на разнице — O(n).

## Окно переменной длины

Общий шаблон:

```js
let left = 0;
for (let right = 0; right < n; right++) {
  // 1. добавить элемент right в состояние окна
  while (/* окно нарушает условие */) {
    // 2. убрать элемент left из состояния, left++
  }
  // 3. окно валидно — обновить ответ (длина right - left + 1)
}
```

Правая граница **расширяет** окно, левая **сжимает**, пока условие не восстановится.
Суммарно left и right делают не больше n шагов каждый → O(n).

## Самая длинная подстрока без повторов

```js
function longestUniqueSubstring(s) {
  const lastIndex = new Map(); // символ → последняя позиция
  let left = 0;
  let best = 0;
  for (let right = 0; right < s.length; right++) {
    const ch = s[right];
    if (lastIndex.has(ch) && lastIndex.get(ch) >= left) {
      left = lastIndex.get(ch) + 1; // прыжок за прошлое вхождение
    }
    lastIndex.set(ch, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

Проверка `>= left` важна: символ мог встречаться **до** текущего окна — тогда он окну
не мешает. Без неё `"abba"` даст неверный ответ.

## Минимальное окно с суммой ≥ target

```js
function minWindowWithSum(nums, target) {
  let left = 0;
  let sum = 0;
  let best = Infinity;
  for (let right = 0; right < nums.length; right++) {
    sum += nums[right];
    while (sum >= target) {
      best = Math.min(best, right - left + 1);
      sum -= nums[left++];
    }
  }
  return best === Infinity ? 0 : best;
}
```

Работает только для **неотрицательных** чисел: с отрицательными сжатие окна может
увеличить сумму, и монотонность ломается. Тогда нужны префиксные суммы.

## Максимальная сумма подмассива (Кадане)

Не окно в чистом виде, но родственная идея «один проход с состоянием»:

```js
function maxSubarraySum(nums) {
  let current = nums[0];
  let best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i]); // продолжить или начать заново
    best = Math.max(best, current);
  }
  return best;
}
```

## Как узнать паттерн в задаче

- «подряд идущие», «подстрока», «подмассив» + «максимальный/минимальный/самый длинный»;
- условие можно пересчитать инкрементально при добавлении и удалении элемента;
- при сдвиге одной границы условие меняется **монотонно**.

## Как это спрашивают

- «Самая длинная подстрока без повторяющихся символов» — одна из самых частых задач.
- «Максимальная сумма k элементов подряд».
- «Минимальная длина подмассива с суммой ≥ target».
- «Найдите все анаграммы подстроки в строке» — окно фиксированной длины с частотами.
- После решения: «какая сложность и почему не O(n²), ведь там вложенный while?» —
  каждая граница двигается только вперёд, суммарно O(n).
